# Portafolio — Juan Gabriel Gualim Molina

Portafolio profesional construido con React + Vite + Tailwind CSS.

## Setup

```bash
npm install
npm run dev
```

Luego abrir http://localhost:5173

## Build para producción

```bash
npm run build
npm run preview
```

## Deploy

El proyecto está listo para deploy en **Vercel** o **Netlify** — solo conectar el repositorio.

## Stack

- React 19
- Vite 8
- Tailwind CSS 3
